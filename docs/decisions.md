# Decisions

Append-only. One line per real choice: date, decision, why.

- 2026-11-22: Hub repo is **Rhodes** (the harbor, Colossus at the entrance). Naming draws on the Seven Wonders; names are picked only when something needs a home.
- 2026-11-22: **Alexandria** (the Pharos) holds knowledge: curated topical memory and generated output, in separate subdirectories (`memory/`, `output/`) so generated material is never mistaken for a source of truth.
- 2026-11-22: Repos are **public but private-information-free**: nothing sensitive is ever committed. Only Chris commits to and changes them; outside PRs against project repos may be entertained, never expected. Claude chat connects through the Claude GitHub App; local git/gh use OAuth (device flow, token in the keyring), never a hand-made personal access token.
- 2026-11-22: Rhodes is the base for the personal work surface. Issues vs a Project board is undecided.
- 2026-11-22: **Never commit to main**, in any repo. Work happens on a working branch and merges by PR, even when the merge is immediate. Working branches are named for the repo's function: `dev` in Rhodes (development), `draft` in Alexandria (content). Project repos use typed branches (`bug/`, `feature/`, etc.). Keep the working branch fast-forwarded to `main` between pieces of work.
- 2026-11-22: The workspace-level `CLAUDE.md` lives in Rhodes (`workspace/CLAUDE.md`) so it is versioned, and `~/Repos/CLAUDE.md` is a symlink to it. It imports `Rhodes/CLAUDE.md` by absolute path so Rhodes's relative paths resolve correctly.
- 2026-11-22: **Work-surface flow (by confidence).** Brainstorming and fleshing out a concept happen in Rhodes (`scratch/`). When something is ready to the point we might write code, it lives in its project repo as a spec; open items are fine. If we drift or learn something, we update the spec in the project so it stays true. Anything old or no longer relevant is archived to Alexandria (`historical/<project>/`; finished knowledge goes to `memory/`), and may be purged from Alexandria later. This keeps Rhodes and the project repos clean.
- 2026-11-24: **Game assets (textures, materials, meshes, archives, audio, plugins, screenshots) and anything derived from them are never committed to any repo; each repo has a `.gitignore` for them.** Creation Kit licence: assets may be modified and distributed for use as mods in Fallout games, not for other use, and posting them on public GitHub allows broader use. We commit the script that makes an asset, never the asset.
- 2026-11-25: **Memory system** (`docs/memory-system.md`): type knowledge, including the Deck runbook and archive notes, lives in Alexandria `memory/<type>/` with frontmatter; context prep lists it with `scripts/memory/memindex.py` when a project is first touched; the only type so far is `fo4-mod`. Scripts stay in Rhodes.
- 2026-11-25: **Repo layout:** `README.md` and `CLAUDE.md` at the root; specs, decisions, notes and working docs in `docs/`, named by the README. One consistent place in every repo.
- 2026-11-26: **Mod releases** (first: Regalia of Mystery): MIT for the build scripts only; the mod itself has plain permissions (free to use, patches welcome, ask before re-uploading or reusing, never sold); published as `voodoogroves`; no Nexus Donation Points or donation links.
- 2026-11-26: Correction to 2026-11-24: no explicit grant to modify and distribute game assets was found in the Creation Kit EULA text (read whole), and Nexus prohibits copyrighted game files without the owner's permission. Shipping recoloured Fallout 4 textures and screenshot-derived art in a mod is an **accepted risk**. Assets still stay out of every repo.
